# Atalay Yapı Dekorasyon

**Mehmet Atalay (Mehmet Usta)** · Bornova / İzmir · 0544 997 87 60

Bornova merkezli ve İzmir geneli hizmet veren işletmenin mobil uyumlu, beyaz-mavi temalı web sitesi. GitHub Pages ile ücretsiz yayınlanacak şekilde hazırlanmıştır. Ek derleme ya da Base44 hesabı gerekmez.

## GitHub Pages yayınını açma

1. GitHub reposunda **Settings → Pages** bölümüne girin.
2. **Build and deployment → Source** alanında **Deploy from a branch** seçin.
3. Branch **main**, folder **/(root)** seçip **Save** tuşuna basın.
4. Birkaç dakika sonra **https://ustarenovasyon.github.io/Mehmet-usta/** adresinden kontrol edin.
5. Yayın açıldıktan sonra ileride özel alan adı bağlanabilir.
